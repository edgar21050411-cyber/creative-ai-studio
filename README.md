# Creative AI Studio

Crea un nuevo proyecto con Supabase habilitado.  "No sé programar. Crea la interfaz visual para un sitio web moderno de IA en modo oscuro. Debe incluir: 1. Un diseño responsivo que se vea genial tanto en computadoras como en teléfonos móviles. 2. Un menú superior (Navbar) con el logo, enlaces a 'Texto', 'Imágenes', 'Video', el saldo de 'Créditos: 50' y el botón de perfil/inicio de sesión. 3. La sección 'Texto': Un chat fluido e intuitivo. 4. La sección 'Imágenes': Un área para ingresar el prompt, selector de estilo, botón de generar y una galería de resultados. 5. La sección 'Video': Similar a imágenes, adaptada para generación de video. 6. Un diseño atractivo que destaque que es una suite de IA sin restricciones de contenido."

This project was built with [Lovable](https://lovable.dev).
